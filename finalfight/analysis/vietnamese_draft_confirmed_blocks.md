# Vietnamese draft — confirmed dialogue blocks

This is a translation draft for the text blocks already located statically.
Control markers are kept in-place and should not be edited until runtime tracing
confirms their exact display behavior.

## Font requirement

The draft intentionally uses uppercase Vietnamese so the existing all-caps style remains consistent.
The final font must support these accented uppercase glyphs:

É È Ẻ Ẽ Ẹ Ê Ế Ề Ể Ễ Ệ
Í Ì Ỉ Ĩ Ị
Ó Ò Ỏ Õ Ọ Ô Ố Ồ Ổ Ỗ Ộ Ơ Ớ Ờ Ở Ỡ Ợ
Ú Ù Ủ Ũ Ụ Ư Ứ Ừ Ử Ữ Ự
Ý Ỳ Ỷ Ỹ Ỵ

Not all of these necessarily need unique tiles if a base-letter/combining-mark renderer is implemented,
but a precomposed tile approach is safer for this game's existing text renderer.
