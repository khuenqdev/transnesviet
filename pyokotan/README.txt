PYOKOTAN NO DAI MEIRO LOCALIZATION TOOLKIT — STAGES 3–5
=======================================================

This bundle contains outputs and tools from stages 3, 4, and 5. The original
pyokotan.nes is intentionally not included; use your own ROM whose SHA-1 is
67fba2e82d78d512466d98bcc9fe11f8e229cb11.

Latest work is under stage5/: full physical CHR tile inventory and atlases,
tile duplicate analysis, a conservative font candidate catalog, an improved
FCEUX trace script that records Mapper 69 PRG/CHR bank parameters plus PPU
writes, and an analyzer that derives estimated physical PRG/CHR offsets.

Start with stage5/outputs/pyokotan_rom_analysis_v5.txt and
stage5/outputs/runtime_trace_instructions_v2.md.

The toolchain remains a reverse-engineering aid, not a complete dialogue dump.
No live emulator trace or Vietnamese-patched ROM is included.
