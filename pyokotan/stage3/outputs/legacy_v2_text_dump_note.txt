Historical artifact note
========================
The v2 text dump generated in the prior stage used a .tbl loader that stripped
trailing whitespace from each mapping line. Its `20= ` (space character) mapping
was therefore accidentally loaded as an empty string, and its decoded original_text
values omit spaces. Do not use legacy_v2_text_dump_pre_space_fix.json for translation.
Use pyokotan_text_dump_v3.json, generated by the fixed loader; it checks that the
string length in characters equals the source payload's byte length for these
single-byte mappings.
